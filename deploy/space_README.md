# Human First

**AI when it helps. People when it matters.**

Human First checks each prompt before it reaches Claude. Personal questions go back to the people in your life,
high-stakes questions to professionals, and searchable questions to the tools that already answer them. It also
shows how much energy and water your AI use costs.

Try the web chat here, or download the Chrome extension from the "Try it" page to use it on claude.ai.

Source code and full documentation: https://github.com/allisonjpiper/humanfirst

**Privacy:** prompts you type are stored on this server so your footprint can be shown. Please don't type anything
you wouldn't want the app's owner to see.
